# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] — 2026-05-21

### Added
- Initial release
- Player respawn detection via `world.afterEvents.playerSpawn`
- Random coordinate generation (500–5000 block range)
- Safe teleport using `player.teleport()` with Resistance V
- Script module using `@minecraft/server` 1.19.0
- Pack icon and documentation
